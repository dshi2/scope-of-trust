# Case-coverage report (expansion batch ba)

Generated by `generate_ba.py`. Describes prespecified case categories and eligibility only. It contains no model results, and cases are never added or dropped based on model behaviour.

**Pre-declared batch rule.** With 12 independent cases (6 base + 6 extension) the case-clustered intervals are wide, so the PI approved expanding the development set to 36 cases as a separately declared batch run (three batches of 8: `ba`, `bb`, `bc`). This batch is run separately with the same frozen model configuration (`configs/p2_dev_eval_v1.json`), renderer, system prompt, task text and condition matrix as the base run (`stimuli_dev.jsonl`, sha256 `368e1d0e…8e67`) and the extension run (`stimuli_ext.jsonl`, sha256 `c9d92a01…63d0`). The batch was authored after the 12-case run; its cases were not selected or edited based on any model output, and base and extension artifacts are unchanged. Batch results are reported as a separately declared batch, never merged silently into the 12-case results.

- Independent cases in this batch: **8** (all synthetic, builder-written development cases; pending welfare-expert review)
- Combined with base + extension: **20** cases, 20 distinct species × practice × indicator families (batch families new to the set: 8 of 8)
- Cells per case: 14 (10 conditions; E and E_scope crossed with 3 outcome directions)
- Contexts per cell: 2 (attribution, belief)
- Eligibility: every case is eligible for every cell by construction (8 × 14 = 112 cells, all filled)

## What this batch adds

- **Species:** breeding ewes, dairy goats, feedlot beef cattle, farmed red deer, alpacas, livery horses, farrowing sows and litters, dairy water buffalo (prior 12: broilers, laying hens, pigs, dairy cows, salmon, turkeys, ducks, rabbits, dairy calves).
- **Practice types:** treatment protocol, milking hygiene, shade provision, transport duration, grazing stocking rate, forage ration, farrowing pen design, bedding depth.
- **Outcome evidence sources and windows:** contracted scorer (4 visits a year), medicine book and vet notes reconciled with prescriptions (per year), camera-based sensor logs (15:00 daily, June to September), abattoir dressing reports (per consignment), veterinary laboratory reports (4 sampling rounds a year), vet call-out log reconciled with practice visit records (per resident horse), herd software reconciled with fallen-stock tickets (per litter), milk-recording technician scoring (4 quarterly visits).
- **Issuers:** eight new fictional issuers (none shared with the base or extension sets).

## Not covered (known gaps, unchanged by this batch)

- **Template diversity: one family.** Batch cases use the same audit-record layout (`kv-record-v1`) and dossier layout as the base cases, by design (same renderer). Format-specific behaviour still cannot be separated from the effect.
- **Period and population scope.** No condition varies the audited period or audits a subset of the population.
- **Independence.** All cases come from builder sessions working to one convention set. Analysis must cluster on case.
- **Realism.** Thresholds, indicators and methods are unreviewed placeholders (spec §8.6). `EXPERT_VERDICTS.csv` has no rows for this batch yet (human-owned; not written by any generator).
