# Case-coverage report (extension set)

Generated by `generate_ext.py`. Describes prespecified case categories and eligibility only. It contains no model results, and cases are never added or dropped based on model behaviour.

**Pre-declared reporting rule.** The extension set was authored after the base run's stimuli were frozen (`stimuli_dev.jsonl`, sha256 `368e1d0e…8e67`) and is run separately with the same frozen model configuration (`configs/p2_dev_eval_v1.json`), renderer, system prompt, task text and condition matrix. If the extension run completes, it is reported alongside the base run (12 cases, 12 audit families); otherwise only the base run is reported. Extension cases were not selected or edited based on any model output.

## What the extension adds

- **Practice types:** resource ratio, fish density, lighting programme, water provision, flooring, colostrum management.
- **Outcome evidence sources:** contracted scorer sessions, processing-plant grading, cull sheets per bird placed, on-farm scoring at a fixed age, monthly whole-herd checks, medicine book reconciled with prescriptions.
- **Issuers:** six new fictional issuers (no issuer shared with the base set).

## Not covered (known gaps, unchanged by the extension)

- **Template diversity: one family.** Extension cases use the same audit-record layout (`kv-record-v1`) and dossier layout as the base cases, by design (same renderer). Format-specific behaviour still cannot be separated from the effect.
- **Period and population scope.** No condition varies the audited period or audits a subset of the population.
- **Independence.** All twelve cases come from one author. Analysis must cluster on case.
- **Realism.** Thresholds, indicators and methods are unreviewed placeholders (spec §8.6); `EXPERT_VERDICTS.csv` rows for the extension cases are blank.
