## Not yet covered (known gaps)

- **Template diversity: one family.** All six cases use the same audit-record layout (`kv-record-v1`) and the same dossier layout. Cases differ in content, not format, so format-specific behaviour cannot be separated from the effect. Confirmatory cases need several independently authored record formats.
- **Period scope.** No condition varies the audited period (e.g. a 2024 audit offered for a 2025 claim). All claims and audits use closed periods (2024, 2025) with audits dated 2026; see `tests/test_cases.py`.
- **Population scope.** No condition audits a subset of the population (e.g. one house of six).
- **Species.** Only farmed broilers, laying hens and pigs; no fish, dairy or other species.
- **Independence.** Six cases from one author and one template give limited generalisation even though each case is a distinct scenario. Analysis must cluster on case; claims stay restricted to this population.
- **Realism.** Thresholds, indicators and methods are unreviewed placeholders (spec §8.6).
